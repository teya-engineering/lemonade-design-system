# Lemonade prototype

Two jobs, one set of files. Pick the job from the request, then read its workflow and follow it exactly.

| The user wants | Read and follow |
| --- | --- |
| A new screen or flow — "prototype", "mock up", "design", "build a screen" | `workflows/design.md` |
| An existing prototype checked — "review", "check", "audit" a page they give you | `workflows/review.md` |

A request for both — "build this, then check it" — runs the design workflow, then the review workflow on
its result. Paths in the workflows are relative to this skill's folder.
