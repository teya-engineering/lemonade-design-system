Colour

Semantic tokens only. They follow the theme, so the same markup is correct in dark mode. The full list, with what each colour is for, is in llms.txt.

Icons

An icon is a mask, so it takes currentColor. Name it with data-icon, using a name from the list below; a name that doesn't exist draws nothing, and the build refuses it. Sizes: lmnd-icon--x-small (12) to --xx-large (40); the default is 20.

Button

The package's own Button. At most two per screen: the primary (Primary · Solid · Large) above a Neutral · Subtle secondary. Secondary is a branded treatment, never "the second button". lmnd-kit-button--full-shape gives the pill shape (SwiftUI's .fullShape()), which a text button in a top bar or sheet bar always takes. A full-width button is the plain button in a column, which stretches it with its label centred; lmnd-button--expand pushes the label to the start and is only for a label followed by a trailing chevron-right, as in a widget's action.

Icon button

Defaults to Neutral · Subtle · Medium (48) · Rounded. Variant: --primary, --secondary, --critical, --on-brand, --on-color. Type: --solid, --ghost. Size: --large, --small, --x-small. Shape: --circular.

Chip

A chip that is a <label> around a hidden input selects itself as it's tapped, with no script: a radio to pick one of a group (give the group one name), a checkbox to pick any. lmnd-kit-chip--selected fixes the state for a static screen, and a chip that opens a sheet, like a filter, is a link.

Symbol container

The leading slot for anything that isn't a plain icon: initials, logos, flags, or an icon with a voice. Sizes --x-small (24) to --xx-large (72), default 40. The icon inside takes the same size name as the container (lmnd-kit-symbol--large holds lmnd-icon--large, --xx-large holds --xx-large); initials take body-xsmall-semibold at x-small, body-small-semibold at small and the default, then body-large-semibold, body-xlarge-semibold and heading-small.

Flags and logos

Flags by ISO code (data-flag="PT"), logos by name (data-logo="mastercard"). Both are full-colour artwork from the stylesheet; size them with lmnd-kit-flag--large and the like. Logos switch to their dark artwork in dark mode.

Card

Rows that belong together go in one card. A card of list items has no padding, so the rows' dividers reach its edges; a card of free content takes lmnd-kit-card--pad-medium. Cards are white on the subtle page (LDS-CARD-SURFACE), 16px apart on a screen (APP-SPACING-RHYTHM); --subtle and --elevated are for a card inside a card or a coloured area.

Text field

A real <input>, so typing and focus work. States: lmnd-kit-field--error, lmnd-kit-field--disabled, lmnd-kit-field--focused (to show focus on a static screen). Text elsewhere that repeats what's typed, such as a new role's name in the footer, carries data-lmnd-kit-mirror="the-input-id" and, for while the field is empty, data-lmnd-kit-mirror-empty; with the kit's script it follows the field.

Text area

Lemonade's TextArea, for free text such as "Tell us what happened": the text field with a <textarea> in a box 180px tall (--lmnd-kit-field-height changes it), padded 16px, the text from the top. A limit goes on the textarea as data-lmnd-kit-max-length with a lmnd-kit-field__counter in the footer; it never blocks typing. Past the limit the counter takes lmnd-kit-field__counter--over, and the screen shows an error and holds back submission. With the kit's script the counter follows what's typed.

Select field

Looks like a text field and opens a picker (LHK-SELECT-OPENS). To open a kit sheet or dropdown, the box is a link to its id; an empty value shows data-placeholder. To open the phone's own picker, the box holds a lmnd-kit-field__select, a native <select> whose empty first option is the placeholder.

Switch, checkbox, radio

Native inputs with lmnd-kit-switch (add role="switch"), lmnd-kit-checkbox, lmnd-kit-radio. Wrap one in lmnd-kit-control for a label and support text.

Box selection

A selectable container around free content. A hidden radio as the first child drives it; lmnd-kit-box-selection--selected fixes it.

Segmented control

Large (48) by default, and always Large when it switches what a whole screen shows (APP-SEGMENTED-SIZE); --medium (40) and --small (32, with body-xsmall-medium) inside a card, widget, sheet or form. Radios drive it.

Tabs

Hug by default; lmnd-kit-tabs--stretch for two or three equal tabs. Repeat the label in data-label so it doesn't shift when it turns semibold.

Top bar

Navigation: a back or close button, a centred title that shows when lmnd-kit-top-bar--collapsed, and the large title below. On a screen, the large title goes first in the content as a lmnd-kit-large-title, so it scrolls under the bar, and the kit's script collapses the bar as it does (examples/settings.html). Small (lmnd-kit-top-bar--small): only the centred title, naming the kind of thing, for a details screen; on lmnd-kit-screen--details it starts transparent and fills on scroll. Compact: a top-level screen's large title with actions beside it, no back button. Buttons are Subtle, or Primary · Solid for the screen's primary action (LDS-TOP-BAR-ACTIONS).

Dropdown

A menu under the button that opens it, such as a top bar's "+" or a view-mode switch. On a screen it is a lmnd-kit-dropdown-layer with an id, after the lmnd-kit-screen, opened by a link to #its-id like a sheet; the layer's dismiss link closes it. It sits under the top bar's trailing button, or under the leading edge with lmnd-kit-dropdown-layer--start. Sections get an upper-case title and a divider between them; the current choice is ticked with check-small; a destructive item takes lmnd-kit-dropdown__item--critical.
