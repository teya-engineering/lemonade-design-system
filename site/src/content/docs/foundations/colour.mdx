Every colour below is read at build time from `tokens/theme-colors.json` — the same
file the Kotlin and Swift token converters generate from. When design re-exports the
Figma collection, this page changes with it. Nobody updates it by hand.

Each token carries its light and dark value, the guidance design wrote in Figma, and
the symbol to use on each platform. Tokens marked **fixed** resolve to the same value
in both themes, on purpose — they are for surfaces that must not flip.

:::caution[Reach for these, not the primitives]
These are the semantic tokens. The primitive palette underneath them
(`blue/500`, `green-lime/alpha/200`, and so on) exists to define these, not to be used
in product code. See [Semantic tokens first](../../standards/semantic-tokens/).
:::
